Privacy & API Keys

Your API key
Signing in with OpenRouter issues an API key for Doom Decisions. The app keeps it in page memory, not localStorage. Refreshing clears the app's local access but does not revoke the issued key.

What gets sent
When using OpenRouter, your browser sends Doom screenshots, instructions, and game context directly to OpenRouter. OpenRouter may forward the request to the selected model provider.

Inspect the code
The deployed site includes source maps, so you can inspect its TypeScript. In Chrome, open DevTools → Sources to explore the code or Network to inspect API requests. Don't share network captures containing API credentials.

Manage or revoke keys in OpenRouter key settings.

Limits & stopping

Use positive JavaScript safe integers for tics and the attempt budget. Tics set each decision's duration in both modes; changes during a run apply to later decisions. The API-attempt budget is fixed when you choose Start.

Budget includes failed and canceled API attempts.

Stop closes admission and waits for API cleanup or current-action and resulting-frame verification. It does not cancel an in-flight operation instantly.
