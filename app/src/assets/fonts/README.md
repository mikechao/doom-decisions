This is the unmodified Google Fonts Latin WOFF2, normal style, with one variable
weight axis (200–700). The UI uses 400, 500 and 600 for display roles; body text
uses system sans-serif. Only this one font file ships, with no italic or additional
language subsets. Characters outside the subset use the CSS fallback stack.
The CSS URL is relative so Vite can emit it for relative deployment bases.
